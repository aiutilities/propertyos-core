# PropertyOS Website

Version: Repository Foundation

---

# Purpose

The PropertyOS website is the public face of the project.

Its purpose is to communicate:

- vision;
- downloads;
- documentation;
- community;
- marketplace;
- releases;
- governance;
- certification.

The website itself is not part of the runtime platform.

---

# Product Freeze Boundary

During Repository Foundation:

- no frontend runtime changes are authorized;
- no backend runtime changes are authorized;
- no APIs are modified;
- no authentication behaviour changes;
- no SDK behaviour changes.

This phase documents the public website only.

---

# Primary Audience

The website serves:

- developers;
- operators;
- property owners;
- enterprises;
- contributors;
- partners;
- plugin developers;
- theme developers.
