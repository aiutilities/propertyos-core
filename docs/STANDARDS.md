# PropertyOS Documentation Standards

Version: 3.0

Every document in PropertyOS must follow the same structure.

## Standard Sections

1. Executive Summary
2. Purpose
3. Scope
4. Definitions
5. Design Principles
6. Architecture
7. Workflows
8. Examples
9. Best Practices
10. Future Roadmap
11. References

---

## Writing Style

- Professional
- Enterprise-grade
- Vendor neutral
- Concise
- Diagram driven
- Example driven

---

## Markdown Standards

Use

- Headings
- Tables
- Mermaid diagrams
- Code blocks
- Notes
- Warnings
- Decision records

Avoid

- Long paragraphs
- Duplicate explanations
- Unstructured lists

---

## Documentation Principles

Documentation is treated like source code.

Every architecture decision must be documented.

Documentation must evolve together with implementation.
