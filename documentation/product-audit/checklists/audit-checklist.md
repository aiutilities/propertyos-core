# Visual Audit Checklist

For every screen verify:

- page loads successfully
- page title is correct
- navigation is correct
- breadcrumb is correct
- content renders
- search works when applicable
- filters work when applicable
- pagination works when applicable
- create action works when applicable
- edit action works when applicable
- delete or archive works when applicable
- validation works
- empty state exists
- loading state exists
- success feedback exists
- error feedback exists
- responsive layout is usable
- permissions are enforced
- browser console contains no errors
