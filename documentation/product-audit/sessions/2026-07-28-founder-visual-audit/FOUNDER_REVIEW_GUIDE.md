# Founder Review Guide

## Objective

Review PropertyOS as a founder, not as a developer.

Every screen should answer four questions.

1. Does it look professional?
2. Does it feel intuitive?
3. Can a first-time user understand it?
4. Would I proudly demo this to an investor or customer?

---

## Rating

5 = Production Ready

4 = Needs Polish

3 = Acceptable

2 = Pilot Blocker

1 = Broken

0 = Cannot Review
