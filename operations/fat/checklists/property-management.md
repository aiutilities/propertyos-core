# PropertyOS FAT — Property Management

## Preconditions

- [ ] Isolated environment is active.
- [ ] Authorized FAT test data may be written.
- [ ] Test administrator is authenticated.

## Acceptance Checks

- [ ] Property creation succeeds.
- [ ] Property details can be retrieved.
- [ ] Property details can be updated.
- [ ] Zone or structural hierarchy can be created.
- [ ] Space or unit can be created.
- [ ] Space details can be updated.
- [ ] Property listing and search behave correctly.
- [ ] Invalid data is rejected.
- [ ] Unauthorized modification is rejected.
- [ ] Audit evidence is created where required.

## Evidence

- [ ] Created identifiers are recorded.
- [ ] Validation failures are preserved.
- [ ] Authorization failures are preserved.
- [ ] Founder result is recorded.

## Safety Boundary

All records created by this checklist must remain isolated FAT data.
